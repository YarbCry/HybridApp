# Lesson 7 implementation

Use the existing `explore` tab as the Lesson 7 screen. Keep demo data and presentation local to it because this is a self-contained teaching exercise. Use React Native `View`, `Text`, `Pressable`, `Alert`, `FlatList`, and `ScrollView`. The existing Expo Router tabs demonstrate bottom tab navigation. A small in-screen tab switcher illustrates tab state. A nested Expo Router `Drawer` at `drawer-demo/` provides real drawer navigation between three routes. SDK 58 already includes the drawer and required native dependencies.

Use NativeWind classes for styling. Verify lint, TypeScript, and Expo exports. No persistence or remote data is involved. The drawer is a learning demo, not the app's main navigator.
