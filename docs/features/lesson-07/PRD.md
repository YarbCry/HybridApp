# Lesson 7 React Native components

Goal: turn the supplied lesson pages into runnable examples in the existing Expo app.

Acceptance: a student can open Lesson 7 from the bottom tab bar; try a native alert; browse a virtualized list; scroll a longer set of content; switch between tabs; open and close a drawer. Examples use supported React Native APIs. The lesson screen works on iOS, Android, and web where supported.

The book's `ListView` has been removed, so its list example is implemented with `FlatList`. The app is already created, so the project creation instructions are documented rather than repeated.
